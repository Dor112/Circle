# Тестирование с друзьями на вашем Windows-ПК

Компьютер работает сервером Круга. Друзьям нужны браузер и Tailscale. VPS, домен, Docker и проброс портов на роутере для этого варианта не требуются. Данные остаются в папке `data/` на вашем ПК; Tailscale обеспечивает сетевой доступ. Если прямое VPN-соединение невозможно, Tailscale может использовать свой релей.

## 1. Настройте общую VPN-сеть

1. Установите [Tailscale для Windows](https://tailscale.com/download/windows), откройте его из меню «Пуск» и нажмите **Log in**. Вход или регистрацию выполните самостоятельно в браузере.
2. В [админ-консоли Tailscale, Users](https://login.tailscale.com/admin/users) пригласите друзей **участниками вашей сети (tailnet)**. Каждый использует свой аккаунт. Друзья устанавливают Tailscale на свои устройства, принимают приглашение и выбирают вашу сеть.
3. Убедитесь в разделе Machines, что устройства подключены. Если в вашей сети включено одобрение новых устройств, одобрите их. Учитывайте лимит участников своего тарифа Tailscale; не выбирайте платную подписку без необходимости.

Для этой схемы нужны участники **одной сети**, которым её правила разрешают соединяться друг с другом. Одного Share отдельного устройства между разными сетями может хватить для сайта, но недостаточно для прямых медиасоединений между всеми друзьями. Не включайте Exit Node: перенаправлять весь интернет-трафик через ваш ПК не требуется.

## 2. Запустите Круг для друзей

1. Остановите прежний локальный сервер: **Ctrl+C в окне, где запущен `start.cmd` или `npm start`**. Аккаунты и история сохранятся.
2. Дважды нажмите **`start-friends.cmd`** в папке проекта.
3. Если Tailscale требует прав, запустите файл правой кнопкой → **«Запуск от имени администратора»**. Если требуется включить HTTPS, Tailscale напечатает ссылку: откройте её, включите HTTPS для вашей сети и запустите файл снова. Для ручной настройки в PowerShell администратора:

```powershell
& 'C:\Program Files\Tailscale\tailscale.exe' serve --bg --https=443 http://127.0.0.1:3000
```

   При первом включении HTTPS имя узла попадает в публичные журналы сертификатов, как описано в документации Tailscale; содержимое Круга от этого публичным не становится. Выберите нейтральное имя устройства, если не хотите публиковать текущее.

4. В окне появится **`ВАША ССЫЛКА: https://имя-пк.имя-сети.ts.net`**. Отправьте друзьям именно её. Окно сервера оставьте открытым. Вы сами тоже открываете эту HTTPS-ссылку, а не localhost.
5. Создайте аккаунт в Круге, сервер и приглашение. Друзья входят в Круг под отдельными аккаунтами и принимают приглашение. Доступ к VPN и приглашение в Круг — два разных шага.

Сценарий использует Tailscale Serve, который предоставляет HTTPS только внутри вашей VPN-сети. **Funnel не нужен.** Скрипт не перезаписывает прокси других приложений и отказывается запускаться при обнаружении публичного Funnel.

Скрипт задаёт `PUBLIC_URL`, Secure cookie и loopback-адрес только для этого запуска. Файл `.env` и папка данных сохраняются. Перенастраивать Windows Firewall или открывать порт 3000 наружу для HTTPS-прокси не нужно.

## 3. Проверьте с другом

1. Пусть друг попробует подключиться из другой сети — например, с мобильного интернета. Tailscale должен быть включён у обоих.
2. Проверьте текст, отправку файла, вступление по приглашению.
3. Откройте один голосовой канал, нажмите «Присоединиться» на обоих устройствах, разрешите микрофон. Проверьте звук в обе стороны, камеру и экран.

VPN улучшает сетевую доступность, но успешная загрузка сайта не гарантирует WebRTC в любом браузере. При проблемах с голосом проверьте, что друзья именно в общей tailnet и правила сети разрешают связь между их устройствами, разрешения микрофона и выбранные аудиоустройства. Не отключайте firewall целиком. Если браузер не получает пригодных ICE-кандидатов VPN или сеть мешает медиасоединению, потребуется отдельный TURN; инструкция его размещения есть в основном README. Фактический разговор через VPN до проверки с другом не считается подтверждённым.

## Остановка и повторный запуск

- **Ctrl+C** в окне Круга останавливает приложение. Следующий запуск — снова `start-friends.cmd`.
- Для удаления только HTTPS-маршрута Круга выполните в PowerShell администратора:

```powershell
& 'C:\Program Files\Tailscale\tailscale.exe' serve --https=443 off
```

- Для возвращения к тестам только на своём ПК остановите режим друзей и используйте `start.cmd` → `http://localhost:3000`.
- Для просмотра состояния: `& 'C:\Program Files\Tailscale\tailscale.exe' status` и `& 'C:\Program Files\Tailscale\tailscale.exe' serve status`.
- Когда ПК выключен, спит, потерял интернет или окно сервера закрыто, Круг недоступен. Не меняйте настройки сна без необходимости: для теста достаточно оставить ПК включённым.

## Переезд на постоянный сервер

Остановите приложение, сохраните копию всей папки `data/` и перенесите её на Linux-сервер. При использовании Docker Compose данные нужно поместить в том `krug_data` до запуска приложения, с правами пользователя `node` (UID 1000); см. резервное копирование и восстановление в README. Настройте домен, HTTPS и TURN по основной инструкции. Аккаунты, сообщения, серверы и файлы переедут вместе с БД. Старые ссылки-приглашения с доменом `ts.net` замените ссылками с новым доменом; сами коды действуют до истечения срока.
