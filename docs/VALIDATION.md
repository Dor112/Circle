# Результаты проверки

Дата: 21 октября 2026. ОС: Windows. Node.js: 24.20.0.

## Дополнение: тестирование с друзьями на Windows-ПК

Установлен официальный Tailscale 1.104.1 через winget. После подтверждённого пользователем включения HTTPS настроен закрытый Tailscale Serve, без Funnel. Приложение запущено через `scripts/start-friends.mjs`: слушает `127.0.0.1:3000`, использует внешний HTTPS Origin, Secure cookie и доверенный локальный прокси.

Страница входа открыта во встроенном браузере по действительному HTTPS-адресу узла `*.ts.net`. Health-check через HTTPS/IPv4 возвращает `200 {"ok":true}` с обычной проверкой сертификата. Обычный Node fetch в этой среде завершился тайм-аутом выбора маршрута; явный IPv4 и браузер работают.

После добавления режима друзей `npm.cmd test`: **12 сценариев успешно**, включая две проверки настроек запуска — loopback/Secure cookie и отказ от перезаписи другого Serve/Funnel. Реальный звонок через VPN с другим устройством ещё требует проверки с другом. Участники VPN не приглашались автоматически.

## Автоматизированная проверка

`npm.cmd test`: 10 сценариев успешно, 0 ошибок. Запускается отдельный HTTP-сервер, используются реальные HTTP-запросы и клиенты Socket.IO, отдельная временная SQLite и три тестовых аккаунта. Среди проверок: приватность файлов и личных сообщений, недопустимый Origin, права владельца, доставка событий, запрет сигналинга постороннему, отзыв доступа после исключения, завершение сессии и перезапуск сервера с сохранением истории.

`node --check server.js` и `node --check public/app.js`: успешно.

`npm.cmd audit --omit=dev --audit-level=high`: на момент проверки 0 известных уязвимостей.

## Проверка в браузере

Встроенный Chromium, адрес `http://localhost:3000`:

- Регистрация отдельного локального тестового аккаунта и вход.
- Создание сервера с текстовым и голосовым каналами.
- Отправка сообщения, отображение автора, времени и эмодзи.
- Поиск существующего сообщения на русском языке.
- Генерация ссылки-приглашения.
- Визуальная проверка в узком и широком представлении; на узком экране каналы доступны через ☰.
- Снимок результата: [preview.png](preview.png). Показанные аккаунт, сервер и сообщение созданы для проверки, это не пользовательская переписка.

Тестовая БД интерфейса удалена после проверки. Приложение передаётся без предустановленных аккаунтов и известных паролей.

## Не подтверждено в этой среде

- Реальное аудио, камера и демонстрация экрана между двумя физическими устройствами. Разрешение на использование личных камеры и микрофона не запрашивалось. Серверная авторизация голосовых комнат и обмен SDP/ICE проверены автоматически.
- Развёртывание контейнеров: Docker на компьютере не найден. Compose, Dockerfile и Caddyfile подготовлены; команды запуска и проверки включены в README.
- Работа TURN, домена, публичного HTTPS и firewall внешнего VPS: внешний сервер и домен не предоставлены.
- Нагрузочная проверка, длительные звонки и мобильные ОС.

Перед первым использованием по интернету выполните четырёхшаговую проверку с другом из README. Успешный тест сигналинга сам по себе не гарантирует проходимость медиатрафика через конкретный NAT или firewall.
